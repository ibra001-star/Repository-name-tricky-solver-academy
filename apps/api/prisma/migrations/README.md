# Why this folder is empty

Prisma migration files are generated by running `npx prisma migrate dev --name init`
against a real, reachable PostgreSQL instance — that command needs to execute actual
SQL against a live database to produce the migration SQL files, so it can't be done
without one.

Run that command once (see the "Database Migrations" section in the root README.md)
to generate your initial migration, then commit the generated `prisma/migrations/`
contents to version control. From then on, this folder holds your real migration
history and this file can be deleted.
